# Shan Shui Generator

Procedural Chinese ink-wash (shan shui) landscape generator — built for Kindle and e-reader screensavers.

Runs entirely in the browser: no build step, no dependencies, no server.

## Live demo

https://nar-io.github.io/shan-shui-generator/

## Features

- Procedural ink landscapes generated in SVG
- Kindle screensaver overlay mode (transparent mist above, solid protected rivers below)
- Export as PNG at full device resolution
- Export as SVG vector

## Local use

```bash
cd docs
python3 -m http.server 8000
# open http://localhost:8000
```
